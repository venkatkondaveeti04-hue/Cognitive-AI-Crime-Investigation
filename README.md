# Cognitive AI Framework for Multimodal Crime Investigation

## Overview
Developed an AI-powered investigative support system for crime analysis and case correlation using Python, Machine Learning, NLP, Google Gemini 2.5, and RAG.

The platform processes multimodal evidence (text, images, audio, and reports), generates investigative hypotheses, performs historical case matching, and visualizes relationships through dashboards and mind maps.

## Key Features
- Multimodal Evidence Analysis
- AI-Powered Hypothesis Generation
- Historical Case Similarity Matching
- Interactive Dashboards & Mind Maps
- Retrieval-Augmented Generation (RAG)
- Secure Evidence Management

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Generative AI
- Google Gemini 2.5
- Retrieval-Augmented Generation (RAG)
- Computer Vision

## Results
- 92–96% Hypothesis Accuracy
- Up to 95% Reduction in Investigation Analysis Time
- 5× Faster Historical Case Matching
